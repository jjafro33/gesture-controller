Connect Tabs
Link this controller to another tab in real time
Method 1 — Same-site demo channel BroadcastChannel

Works instantly between two tabs of this same site (e.g. this controller + the bundled receiver.html demo tab). Open the receiver, then perform gestures here.

Method 2 — Any tab, via extension Not detected

Install GestureCTRL Bridge (folder /extension) as an unpacked Chrome/Edge extension. It receives commands from this page and turns them into real keyboard, mouse, wheel, and fullscreen events on the active tab — works on Poki, YouTube, Google Slides, Canva, or any HTML5 game.

  1. Open chrome://extensions
  2. Enable Developer mode
  3. Click Load unpacked → select the extension/ folder
  4. Open your target tab (Poki, YouTube…) and switch to it
  5. Come back here — gestures now control that tab
